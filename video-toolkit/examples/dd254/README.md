# DD 254 course (six parts, about 53 minutes)

A narrated cartoon course on completing DD Form 254 (APR 2018). It follows one form down the chain: the government builds it, the prime contractor issues a subcontract form, and the subcontractor lives with it.

**Status:** the scripts are written and voiced (4 Oct 2026) and are awaiting the owner's approval. No scenes or renders exist yet.

| File | What it holds |
|---|---|
| `course-handoff.md` | Brief, decisions, constraints, runtimes, the per-scene on-screen plan, verified sources, pronunciation rules, toolkit pitfalls, next steps |
| `surviving-narration.md` | Verbatim narration for the nine scenes added on 4 Oct |
| `google-flow-notes.md` | Constraints for producing the course with Google Flow |
| `flow-pilot-part1.md` | Flow pilot: style lock, cast and location sheets, Part 1 footage/graphics split, clip prompts, pass/fail checklist |
| `dd254-course-script-review.md` | **Missing: add it.** The full narration for all six parts; only the owner's downloaded copy survives |

The script generator, the form-rendering tooling and the voiced audio were lost in a container reset before they were committed. `course-handoff.md` §10 says how to rebuild them.
